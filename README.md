# 🌙 星落之夜

> 纯 HTML/CSS/JS 互动视觉小说 · 无需安装 · 浏览器即玩

**在线体验：** https://chfr19820610-cell.github.io/ai-vn-game/

---

## 关于

星落之夜是一款零依赖、单文件的互动视觉小说游戏。采用纯 HTML/CSS/JavaScript 编写，无框架、无构建步骤、无外部依赖。

**故事简介：** 「六十年前那个走出去的人疯了。你是第二个。」—— 村庄的石碑在呼吸，星辰在移动，你必须在黎明之前做出选择。

---

## 功能

- 🎭 **4个角色** — 旁白🌙·凯尔🧙·莉拉🏹·马库斯🗡️，各有Emoji头像和专属配色
- 🔀 **分支选择** — 好感度系统，选择影响后续剧情
- 💾 **存档系统** — 3手动存档 + 1自动存档（localStorage）
- 🌌 **场景切换** — 8个场景各有独立渐变背景
- 📱 **响应式** — 自适应桌面/平板/手机，安全区域兼容
- ⚡ **零依赖** — 单 HTML 文件，打开即玩
- 🔓 **开源** — Apache 2.0 协议

---

## 使用

```bash
git clone https://github.com/chfr19820610-cell/ai-vn-game.git
cd ai-vn-game
# 直接用浏览器打开 index.html
open index.html
# 或部署到任何静态托管（GitHub Pages/Netlify/Cloudflare Pages）
```
